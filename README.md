# SauceDemo – Manual Testing Project

## 📌 Project Overview

This project demonstrates manual testing of the SauceDemo e-commerce web application.

The objective is to validate the application's core functionality, identify defects, and ensure a good user experience.

## 🌐 Application Under Test

**Application:** SauceDemo
**URL:** https://www.saucedemo.com/

## 🧪 Testing Scope

The following areas are covered:

* Login functionality
* Product listing
* Product details
* Add to cart
* Remove from cart
* Cart functionality
* Checkout
* Order completion
* Logout
* Negative test scenarios
* UI validation

## 🔍 Testing Types

* Functional Testing
* Positive Testing
* Negative Testing
* Regression Testing
* UI Testing
* Usability Testing

## 🛠️ Tools Used

* Manual Testing
* Jira
* Google Sheets / Excel
* Chrome DevTools
* GitHub

## 📋 Test Deliverables

This project contains:

* Test scenarios
* Detailed test cases
* Test execution report
* Bug reports
* Testing evidence/screenshots

## 🎯 Objective

The main objective is to validate the application's functionality against expected behavior and document any identified defects with clear steps to reproduce.
